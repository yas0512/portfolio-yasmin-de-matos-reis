# 🩺 Sistema de Triagem Médica Automatizada

## Objetivo
Projeto acadêmico da disciplina de Engenharia de Soluções Lógicas. A proposta é modelar um fluxo de triagem inicial a partir de sinais vitais e classificar o atendimento em categorias definidas pelas regras do exercício.

> **Aviso:** este é um exercício educacional de lógica e não deve ser utilizado para diagnóstico, avaliação clínica ou decisões médicas reais.

## Dados considerados
- Pressão arterial.
- Frequência cardíaca.
- Temperatura corporal.

## Funcionalidades previstas no exercício
- Leitura de sinais vitais.
- Aplicação de regras condicionais.
- Classificação lógica do atendimento.
- Representação da solução em fluxograma e testes de mesa.

## Tecnologias e conceitos
- **Portugol**
- Algoritmos e lógica de programação.
- Fluxogramas e validação por testes de mesa.

## Materiais
Os arquivos PDF desta pasta reúnem os materiais do projeto. Consulte-os para acompanhar o desenvolvimento da solução.

## Aprendizados
Decomposição de problemas, construção de regras, representação de algoritmos e validação de cenários.
