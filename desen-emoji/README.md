# 🎨 Desenhando Emojis com Dados

## Objetivo
Projeto de prática em Python que explora a representação de figuras e emojis por meio de dados, caracteres e estruturas de programação.

## Funcionalidades e exploração
- Manipulação de caracteres e símbolos Unicode.
- Organização de dados para representar elementos visuais.
- Experimentação com estruturas de repetição e lógica.
- Visualização dos resultados em notebook.

## Tecnologias
- **Python 3**
- **Jupyter Notebook**
- Strings, Unicode e estruturas de dados.

## Como visualizar
Abra o notebook `emoji.ipynb` diretamente no GitHub ou em um ambiente Jupyter Notebook compatível.

## Aprendizados
A atividade relaciona lógica de programação e representação visual, mostrando como dados e caracteres podem ser organizados para formar padrões.
