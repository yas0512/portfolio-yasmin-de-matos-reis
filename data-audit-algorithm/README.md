# 🛡️ Algoritmo de Auditoria e Análise de Vendas

## Objetivo
Este projeto acadêmico apresenta um protótipo de auditoria financeira que analisa registros de vendas e sinaliza valores que podem representar inconsistências ou anomalias (*outliers*).

## Funcionalidades
- Receber valores de vendas como entrada.
- Calcular a média dos registros.
- Comparar os resultados com limites de segurança.
- Sinalizar situações que precisam de quarentena ou revisão manual.
- Explorar o impacto de valores extremos na análise dos dados.

## Tecnologias e conceitos
- **Python 3**
- Variáveis e escopo global/local.
- Estruturas condicionais e operações matemáticas.
- Média aritmética, tolerância e detecção de outliers.

## Como executar
O material atual do projeto inclui documentação e um arquivo de apoio. Para executar uma implementação Python, abra o script correspondente no ambiente Python e execute-o. Confira os nomes dos arquivos disponíveis nesta pasta.

## Aprendizados
O projeto explora como regras de negócio e limites de validação podem apoiar a análise de dados. Os alertas são sugestões para revisão, não uma comprovação de fraude.
