# 🛡️ Sistema de Auditoria de Vendas

## Objetivo
Este projeto em Python simula uma auditoria de vendas para praticar análise de valores, identificação de discrepâncias e uso de variáveis com escopo global e local.

## Funcionalidades
- Trabalhar com valores de vendas definidos no programa.
- Calcular e analisar a média dos valores.
- Comparar resultados com um limite de segurança.
- Sinalizar valores discrepantes para revisão.
- Demonstrar como parâmetros de segurança influenciam a lógica da auditoria.

## Tecnologias e conceitos
- **Python 3**
- Variáveis, funções e escopo global/local.
- Estruturas condicionais e operações matemáticas.
- Média e identificação de valores extremos (*outliers*).

## Estrutura
- `sistema_de_auditoria.py`: script Python da atividade.
- Este README: documentação do objetivo e dos conceitos trabalhados.

## Como executar
Com Python 3 instalado, abra o terminal nesta pasta e execute:

```bash
python sistema_de_auditoria.py
```

## Aprendizados
A atividade explora como regras de negócio podem ser transformadas em condições computacionais e como valores extremos podem afetar a interpretação de um conjunto de dados.
