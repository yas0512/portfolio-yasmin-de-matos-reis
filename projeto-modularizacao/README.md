# 🧩 Modularização — Sistema de Troco

## Objetivo
Este projeto apresenta o planejamento de uma solução para calcular o troco de uma compra usando a menor quantidade possível de cédulas. A atividade enfatiza a decomposição de um problema em etapas menores e a organização da lógica em módulos.

## Como a solução foi pensada
A proposta utiliza a estratégia **Dividir para Conquistar** e os pilares do pensamento computacional:
- **Decomposição:** separar o problema em tarefas menores.
- **Reconhecimento de padrões:** identificar as operações que se repetem.
- **Abstração:** considerar apenas os dados necessários para calcular o troco.
- **Algoritmos:** definir uma sequência clara de passos para chegar ao resultado.

## Módulos planejados
- `validar_pagamento()`: verifica se o valor pago cobre o total da compra.
- `calcular_troco()`: calcula a diferença entre o pagamento e o total.
- `decompor_notas()`: distribui o troco em cédulas de diferentes valores.

## Tecnologias e ferramentas
- Pseudocódigo e fluxogramas.
- Pensamento computacional.
- Planejamento de funções e modularização.
- Documentação em Markdown.

> A atividade é apresentada como planejamento *unplugged* (papel e caneta); portanto, os materiais desta pasta documentam a lógica da solução, não necessariamente um programa executável.

## Aprendizados
A atividade demonstra como dividir uma tarefa em responsabilidades menores facilita a compreensão, a manutenção e a futura implementação de um programa.
