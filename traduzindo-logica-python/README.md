# 🐍 Traduzindo Lógica para Python

## Objetivo
Reunir exercícios de programação que praticam a tradução de enunciados e algoritmos para código Python, reforçando os fundamentos da programação estruturada.

## Conteúdos trabalhados
- Entrada de dados e processamento de vendas.
- Cálculos e análise de temperaturas.
- Cálculo de médias e classificação de notas.
- Simulação de poupança e evolução de valores.

## Tecnologias e conceitos
- **Python 3**
- Variáveis, tipos de dados e conversão de entrada.
- Estruturas condicionais.
- Laços de repetição.
- Funções e operações matemáticas.

## Como executar
Abra o arquivo `traduzindo-logica-python.py` em um editor Python e execute:

```bash
python traduzindo-logica-python.py
```

O arquivo `QeA.md` complementa a atividade com perguntas e respostas sobre conceitos utilizados.

## Aprendizados
Interpretar problemas, planejar algoritmos, transformar lógica em código e testar diferentes entradas.
