# 🏢 Sistema de Auditoria de Recursos Corporativos

## Objetivo
Projeto acadêmico em Python voltado à análise de dados orçamentários de uma estrutura organizacional. A proposta é percorrer departamentos e seus níveis internos, aplicar filtros e registrar informações relevantes durante a execução.

## Funcionalidades descritas
- Percorrer estruturas hierárquicas de dados.
- Calcular valores considerando departamentos e subsetores.
- Permitir ignorar setores selecionados.
- Trabalhar com parâmetros opcionais, como conversão de moeda.
- Registrar informações de auditoria e tempo de execução.

## Tecnologias e conceitos
- **Python 3**
- Dicionários aninhados e recursão.
- Funções e decorators.
- Argumentos variáveis (`*args` e `**kwargs`).
- Logging e medição de tempo.

## Como executar
O repositório contém o notebook `sistema_de_auditoria.ipynb`. Abra-o no GitHub ou em Jupyter Notebook para consultar e executar as células.

## Aprendizados
Organização de dados hierárquicos, decomposição de problemas, reutilização de funções e observabilidade da execução.
